## Filosofía y Enfoque

Para estructurar este repositorio aplico **primeros principios**: entender la mecánica fundamental de cómo funciona cada pieza de tecnología antes de escalar hacia abstracciones más complejas.

Nada de escribir biblias aca. El objetivo de este espacio es:
-   Registrar patrones, snippets y funcionamiento base de algo.
-   Servir como contexto activo para mi y agentes de codigo al momento de hacer un proyecto.
-   Mantener un mapa interconectado y de consulta rápida de mi stack técnico.
