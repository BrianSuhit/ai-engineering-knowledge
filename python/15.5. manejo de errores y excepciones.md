En Python, la captura y el control de errores mantienen una estructura conceptual muy similar a la de Java, pero adaptada a su sintaxis sin llaves y con la adición del bloque `else`.

---

#### **1. Estructura Principal ( try / except vs try / catch )**

- **Java:** Usás `try { ... } catch (Exception e) { ... }`.
- **Python:** La palabra reservada para capturar el error es **except**.

```python
try:
    numero = int("abc")
except ValueError:
    print("El valor ingresado no es un entero válido")
```

---

#### **2. Captura Múltiple de Excepciones**

Podés encadenar varios bloques `except` para manejar distintos tipos de error o capturar varios en una sola línea agrupándolos en una tupla.

```python
try:
    resultado = 10 / int("0")
except ValueError:
    print("Error de conversión de tipo")
except ZeroDivisionError:
    print("No se puede dividir por cero")
except (TypeError, KeyError):  # Captura cualquiera de los dos
    print("Error de tipo o de clave")
```

---

#### **3. El Bloque else (Novedad respecto a Java)**

- **Java:** No existe equivalente directo en la estructura `try-catch`.
- **Python:** El bloque `else` se ejecuta **únicamente si NO ocurrió ninguna excepción** dentro del `try`. Permite separar el código riesgoso del código que solo debe ejecutarse tras un resultado exitoso.

```python
try:
    resultado = 10 / 2
except ZeroDivisionError:
    print("Error: División por cero")
else:
    print(f"Operación exitosa. El resultado es: {resultado}")
```

---

#### **4. El Bloque finally**

Funciona **exactamente igual que en Java**. Se ejecuta **siempre**, se haya producido o no una excepción, y se utiliza para tareas de limpieza o liberación de recursos.

```python
try:
    print("Abriendo proceso...")
except Exception as e:
    print(f"Ocurrió un error: {e}")
finally:
    print("Limpieza finalizada.")  # Se ejecuta SIEMPRE
```

---

#### **5. Lanzar Excepciones ( raise vs throw )**

- **Java:** Usás la palabra clave `throw new MiExcepcion("Mensaje")`.
- **Python:** Se utiliza la palabra reservada **raise**.

```python
edad = -5
if edad < 0
	raise ValueError("La edad no puede ser negativa")
```
