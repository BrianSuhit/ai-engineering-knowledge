**Qué es en criollo:** 

Es una librería de Python que sirve para **crear mapas interactivos directamente desde código sin tener que saber JavaScript**. Por detrás, lo único que hace es envolver una biblioteca web clásica de mapas llamada **Leaflet.js**: vos manipulás datos y coordenadas en Python y Folium te escupe el mapa en HTML interactivo (con zoom, arrastre y capas) listo para ver en el navegador o incrustar en aplicaciones como Streamlit.

**Qué problema resuelve:** 

Resuelve la **dificultad de visualizar datos geoespaciales interactivos en Python sin tener que montar un stack completo de desarrollo web (JavaScript, CSS y librerías de mapas)**. Concretamente soluciona:

1. **Visualización de coordenadas y polígonos:** Permite transformar tablas de latitud y longitud, archivos GeoJSON o geometrías de datos en capas visuales explorables con marcadores, áreas y colores.
2. **Interactividad lista para usar:** Proporciona de forma nativa controles de zoom, desplazamiento, popups informativos y capas base sin tener que programar eventos de interfaz a mano.
3. **Integración fluida con ecosistemas de datos y dashboards:** Se conecta directamente con Pandas y se incrusta en Streamlit o notebooks mediante componentes ligeros, permitiendo que un modelo o agente muestre resultados geográficos de inmediato.

**3. Comandos base esenciales de Folium:**

```python
uv add folium streamlit-folium

import folium
from streamlit_folium import st_folium

# --- 1. OBJETO MAPA BASE ---
mapa = folium.Map(
    location=[-37.32, -59.13],  # [lat, lon] centro inicial
    zoom_start=12,              # Nivel de zoom inicial (ej: 1 al 18)
    tiles="OpenStreetMap"       # Capa de fondo ("OpenStreetMap", "CartoDB positron", etc.)
)

# --- 2. ENCUADRE AUTOMÁTICO (BOUNDS) ---
# Ajusta la vista para que todos los puntos de la lista entren en pantalla
mapa.fit_bounds([[-37.33, -59.14], [-37.29, -59.15]])

# --- 3. MARCADORES Y ELEMENTOS ---
# Pin clásico
folium.Marker(
    location=[-37.33, -59.14],
    popup="Texto al hacer clic",                     # Ventana emergente (soporta HTML)
    tooltip="Texto al pasar el mouse por encima",    # Cartelito flotante rápido
    icon=folium.Icon(color="green", icon="info-sign") # Color ("blue", "red", etc.) e ícono
).add_to(mapa)

# Líneas y rutas (PolyLine)
folium.PolyLine(
    locations=[[-37.33, -59.14], [-37.29, -59.15]],  # Lista de coordenadas conectadas
    color="orange",                                  # Color de trazo
    weight=3                                         # Grosor de la línea en px
).add_to(mapa)

# --- 4. SALIDA Y RENDER ---
# En Streamlit:
st_folium(mapa, width=700, height=500)

# O guardar como archivo web independiente:
# mapa.save("mapa.html")

```

**La trampa o error común:** 

La trampa clásica en Folium es **el colapso del navegador por sobrecarga de marcadores y el bucle de renderizado en Streamlit**.

1. **El DOM saturado:** Folium genera HTML y JavaScript puro (Leaflet.js). Si intentás meter miles de `folium.Marker` individuales directamente en el mapa en vez de agruparlos con clusters (`MarkerCluster`), el navegador del usuario se congela intentando renderizar miles de nodos SVG en pantalla.
2. **Incompatibilidad de coordenadas:** Invertir el orden de las coordenadas pasando `[longitud, latitud]` en lugar de `[latitud, longitud]`, lo que termina mandando los pines al medio del océano o a los polos.
3. **El parpadeo en Streamlit (** **st_folium** **):** Cada vez que el usuario mueve el mapa, hace zoom o clikea un pin, Streamlit vuelve a ejecutar todo el script de arriba a abajo. Si dentro de ese script regenerás el mapa desde cero sin cachear o sin fijar límites, el mapa vuelve a su posición original reseteando la vista del usuario en cada interacción.
