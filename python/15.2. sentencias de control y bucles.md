#### **Selección Condicional ( if , elif , else )**

En lugar de `else if` como en Java, Python sintetiza la condición con la palabra reservada `elif`.

```python
nota = 8
if nota >= 9:
    print("Sobresaliente")
elif nota <= 6:
    print("Aprobado")
else:
    print("Desaprobado")
```

#### **Selección Múltiple ( match / case )**

Es el equivalente moderno al `switch/case` de Java (introducido en Python 3.10), donde `case _:` actúa como el bloque `default`.

```python
comando = "start"
match comando:
    case "start":
        print("Iniciando...")
    case "stop":
        print("Deteniendo...")
    case _:
        print("Comando no reconocido")
```

#### **Bucle while**

Funciona igual que en Java evaluando una condición booleana. Tené en cuenta que en Python **no existe la estructura** **do-while**.

```python
contador = 0
while contador < 3:
    print(contador)
    contador += 1
```

#### **Bucle for (Iterativo / Range)**

El `for` en Python es siempre un *for-each* sobre elementos. Para simular el `for (int i = 0; i < n; i++)` tradicional de Java se utiliza la función `range()`.

```python
# Iterar por rango numérico (de 0 a 4)
for i in range(5):
    print(i)

# Iteración directa sobre colección (for-each)
nombres = ["Ana", "Juan", "Pedro"]
for nombre in nombres:
    print(nombre)
```
