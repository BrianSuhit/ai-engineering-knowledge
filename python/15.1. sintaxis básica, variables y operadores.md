#### **Estructura y Formato (Indentación)**

En Python no existen las llaves `{}` ni el punto y coma `;`. La estructura y delimitación de bloques de código se define obligatoriamente mediante **indentación (4 espacios)**.

```python
if True:
    print("Código dentro del bloque")
```

#### **Variables y Tipos Básicos**

No requieren declaración explícita de tipo (tipado dinámico) y se nombran siguiendo la convención `snake_case`. Los tipos primitivos principales son enteros (`int`), decimales (`float`), texto (`str`) y booleanos (`bool`).

```python
edad = 25            # int
altura = 1.75        # float
nombre = "Brian"     # str
es_estudiante = True # bool
```

#### **Comentarios**

Se utiliza `#` para comentarios de una sola línea y triples comillas `"""` para bloques de comentarios multilínea o documentación (*docstrings*).

```python
# Comentario de una línea

"""
Comentario de varias líneas
o documentación de código
"""
```

#### **Operadores**

Incluye los operadores aritméticos usuales (`+`, `-`, `*`, `/`, `//`, `%`), relacionales (`==`, `!=`, `<`, `>;`) y lógicos expresados mediante palabras en inglés (`and`, `or`, `not`).

```python
suma = 10 + 5               # Aritmético
es_igual = (5 == 5)         # Relacional (True)
condicion = True and False  # Lógico (False)
```
