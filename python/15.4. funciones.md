#### **Definición y Retorno ( def )**

En Python las funciones se definen con la palabra `def`. **No existe la palabra reservada** **void**: si una función no incluye `return` (o usa `return` sin valor), ejecuta su lógica y devuelve automáticamente **None** (el equivalente a `null` en Java).

```python
def mostrar_mensaje(texto):
    print(texto)  # No tiene return, devuelve None automáticamente
```

#### **Documentación de Funciones ( Docstrings )**

Es el estándar para documentar qué hace una función (el equivalente al Javadoc de Java). Se escribe usando triples comillas `"""` en la primera línea interna de la función.

```python
def calcular_impuesto(monto):
    """Calcula el 21% de IVA para un monto dado."""
    return monto * 0.21
```

#### **Type Hints (Anotaciones de Tipo: nombre: str , > None )**

Permiten declarar el tipo esperado de los parámetros y del retorno. **No fuerzan el tipo en tiempo de ejecución** (Python sigue siendo de tipado dinámico), pero sirven como documentación visual y ayuda para el autocompletado del editor.

```python
def saludar(nombre: str) -> None:
    print(f"Hola, {nombre}")
```

#### **Parámetros Posicionales y Nombrados ( Keyword Arguments )**

Podés pasar los argumentos según el orden de declaración (posicionales) o indicando explícitamente el nombre del parámetro (`parametro=valor`), lo que te permite alterar el orden en la llamada.

```python
def crear_usuario(nombre, rol):
    print(f"Usuario: {nombre} | Rol: {rol}")

# Llamada por nombre (permite cambiar el orden)
crear_usuario(rol="Admin", nombre="Brian")
```

#### **Valores por Defecto**

Permiten definir valores predeterminados para parámetros opcionales, evitando la necesidad de sobrecargar métodos como se hace en Java.

```python
def conectar(host="localhost", puerto=8080):
    print(f"Conectando a {host}:{puerto}")

conectar()              # Usa ambos valores por defecto
conectar("192.168.1.1")  # Cambia solo 'host'
```

#### **Retornos Múltiples**

Una función puede devolver varios valores separados por comas. Python los empaqueta automáticamente en una **tupla**, que luego se puede desempaquetar directamente en variables individuales.

```python
def obtener_min_max(numeros):
    return min(numeros), max(numeros)  # Devuelve la tupla (min, max)

menor, mayor = obtener_min_max([5, 2, 9, 1])
```

#### **Parámetros Variables ( args y **kwargs )**

Permiten recibir una cantidad flexible de argumentos sin saber de antemano cuántos se van a enviar:

- `args`: Agrupa argumentos posicionales extra en una **tupla**.
- `*kwargs`: Agrupa argumentos nombrados extra en un **diccionario**.

```python
def procesar_pedido(producto, *descuentos, **detalles):
    print(producto)    # "Notebook"
    print(descuentos)  # Tupla: (10, 5)
    print(detalles)    # Diccionario: {'envio': 'express', 'pago': 'tarjeta'}

procesar_pedido("Notebook", 10, 5, envio="express", pago="tarjeta")
```

#### **Funciones Anónimas ( lambda )**

Son funciones de **una sola línea** sin nombre que se usan para transformaciones rápidas. Un uso típico y muy visual es pasarle una regla de ordenamiento a una lista de datos compuestos:

```python
# Lista de tuplas: (Producto, Precio)
productos = [("Notebook", 1200), ("Mouse", 25), ("Teclado", 80)]

# La lambda toma cada tupla (p) y retorna su PRECIO (índice 1) para ordenar por ese valor
productos.sort(key=lambda p: p[1])

# Lista ordenada de menor a mayor precio:
# [('Mouse', 25), ('Teclado', 80), ('Notebook', 1200)]
```
