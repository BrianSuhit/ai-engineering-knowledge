#### **Clases, Objetos y Constructor**

#### **Definición de Clase y Creación de Objetos**

Una clase es una plantilla o molde que define el comportamiento y el estado de sus instancias. En Python no existe la palabra reservada `new`: para instanciar un objeto se invoca a la clase directamente como si fuera una función.

En **AI Engineering**, este es el patrón universal para inicializar clientes de APIs, modelos locales o conexiones de bases de datos vectoriales:

```python
class ModeloIA:
    pass

# Instanciación directa (sin 'new')
llm = ModeloIA()
```

---

#### **El Constructor ( __init__ ) y el parámetro self**

El método especial `__init__` actúa como constructor y se ejecuta automáticamente al instanciar el objeto para asignar sus valores iniciales.

- **self** **:** Representa la instancia concreta que se está ejecutando (equivalente a `this` en Java) y debe ser obligatoriamente el primer argumento de los métodos de instancia.
- Permite fijar el estado interno (como la API key, el nombre del modelo o la temperatura) para que todos los métodos de la clase puedan acceder a él.

```python
class AsistenteTandil:
    def __init__(self, modelo: str, temperatura: float = 0.2):
        self.modelo = modelo            # Atributo asignado a la instancia
        self.temperatura = temperatura

# Cada instancia guarda su propia configuración
asistente_auditor = AsistenteTandil("gemini-2.5-flash", 0.0)
asistente_creativo = AsistenteTandil("gemini-2.5-flash", 0.7)
```

---

#### **Atributos de Instancia vs. Atributos de Clase**

- **Atributos de instancia:** Se definen con `self.` dentro de los métodos (típicamente en `__init__`) y son únicos e independientes para cada objeto.
- **Atributos de clase:** Se declaran directamente en el cuerpo de la clase fuera de cualquier método. Son compartidos por todas las instancias (equivalente conceptual a los atributos `static` de Java). En IA se usan comúnmente para constantes del sistema, endpoints base o versiones de esquemas.

```python
class ClienteAuditoria:
    PROVEEDOR = "Google"  # Atributo de clase (compartido por todas las instancias)

    def __init__(self, coleccion_chroma: str):
        self.coleccion_chroma = coleccion_chroma  # Atributo de instancia (único)

# Acceso directo por clase
print(ClienteAuditoria.PROVEEDOR)  # Google

# Acceso por instancia
cliente_pdt = ClienteAuditoria("ordenanzas_tandil")
print(cliente_pdt.coleccion_chroma)  # ordenanzas_tandil
```

#### **Encapsulamiento y Visibilidad**

#### **Convención de Atributo Protegido ( _ )**

En Python **no existen** **private** **ni** **protected** **como palabras reservadas**. Rige la filosofía de *"todos somos adultos responsables"*:

- **_atributo** **(un guion bajo):** Es la convención universal para avisarle a otro programador que una variable o método es de uso interno. Python no te bloquea el acceso físico, pero no deberías tocarlo desde afuera.
- En IA se usa típicamente para clientes de conexión, buffers o caches internas que la aplicación no debe manipular directamente.

```python
class MotorRAG:
    def __init__(self, api_key: str):
        self.modelo = "gemini-2.5-flash"  # Público
        self._cliente_api = self._iniciar_cliente(api_key)  # Protegido / Interno

    def _iniciar_cliente(self, key: str):
        # Método interno auxiliar
        return f"Cliente conectado con {key[:4]}..."
```

#### **Herencia Simple y super()**

#### **Especialización y Extensión**

Para heredar, simplemente se pasa la clase padre entre paréntesis: `class Hija(Padre):`. Con `super().__init__(...)` delegás la inicialización al constructor padre sin duplicar código.

En IA tiene dos usos principales:

1. **Crear excepciones de dominio** (para cortar ejecuciones cuando falla una validación de contexto o de API).
2. **Esquemas de datos con Pydantic:** Al heredar de `BaseModel`, tu clase adquiere automáticamente validación de tipos y serialización JSON *(ver nodo específico de Pydantic)*.

```python
# Caso de uso real: Excepción personalizada de IA
class ErrorDeContexto(Exception):
    def __init__(self, mensaje: str, tokens_excedidos: int):
        super().__init__(mensaje)  # Inicializa la clase base Exception
        self.tokens_excedidos = tokens_excedidos

# Uso
if tokens >= 8000:
    raise ErrorDeContexto("Prompt demasiado largo", tokens_excedidos=tokens)
```

#### **Polimorfismo y Duck Typing**

#### **"Si camina como pato y grazna como pato..."**

En Java el polimorfismo exige interfaces formales (`implements Procesador`). En Python, a una función no le importa la clase ni la jerarquía del objeto: solo le importa **que el objeto tenga el método que necesita ejecutar**.

En pipelines de IA esto es vital: permite intercambiar proveedores de modelos (Gemini, local, mock de pruebas) sin necesidad de una clase abstracta común:

```python
class GeminiLLM:
    def generar(self, prompt: str) -> str:
        return "Respuesta de Gemini"

class ModeloLocal:
    def generar(self, prompt: str) -> str:
        return "Respuesta de Llama local"

# Duck Typing: espera cualquier cosa con .generar()
def ejecutar_auditoria(proveedor, texto_proyecto: str):
    return proveedor.generar(texto_proyecto)

print(ejecutar_auditoria(GeminiLLM(), "Loteo Tandil"))
print(ejecutar_auditoria(ModeloLocal(), "Loteo Tandil"))
```

#### **Constructores Alternativos ( @classmethod )**

#### **El decorador @classmethod y cls**

Recibe la propia clase (`cls`) en lugar de la instancia (`self`). Es el patrón estándar de la industria (patrón *Factory*) para instanciar clases de formas alternativas, por ejemplo leyendo variables de entorno o cargando archivos de configuración:

```python
import os

class ConfiguracionAgente:
    def __init__(self, api_key: str, ambiente: str):
        self.api_key = api_key
        self.ambiente = ambiente

    @classmethod
    def desde_entorno(cls):
        # Factory method: lee el SO y retorna una nueva instancia cls(...)
        key = os.getenv("GEMINI_API_KEY", "default_key")
        env = os.getenv("APP_ENV", "development")
        return cls(api_key=key, ambiente=env)

# Instanciación limpia y directa sin lidiar con os.getenv en el main
config = ConfiguracionAgente.desde_entorno()
```

#### **Modelado de Datos Moderno ( @dataclass )**

#### **Estructuras limpias sin código repetitivo**

En lugar de escribir clases tradicionales con `__init__`, asignaciones manuales (`self.x = x`), `__repr__` para que se imprima legible y `__eq__` para comparar objetos, Python incluye el decorador nativo `@dataclass`.

En IA y pipelines de datos es el estándar para representar chunks, resultados de búsqueda vectorial o mensajes de chat internos sin dependencias externas:

```python
from dataclasses import dataclass

@dataclass
class FragmentoLegal:
    id_norma: str
    texto: str
    relevancia: float
    fuente: str = "PDT_Tandil.pdf"  # Valor por defecto

# __init__ automático con tipado
chunk1 = FragmentoLegal("IV.12", "Prohibido efluentes...", 0.89)
chunk2 = FragmentoLegal("IV.12", "Prohibido efluentes...", 0.89)

# __repr__ automático (imprime claro, no la dirección de memoria)
print(chunk1)  # FragmentoLegal(id_norma='IV.12', texto='Prohibido...', ...)

# __eq__ automático (compara valores, no referencias)
print(chunk1 == chunk2)  # True
```
