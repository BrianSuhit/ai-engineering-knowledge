**Qué es en criollo el tema:** 

Es la herramienta nativa de Python que transforma las rutas de archivos de simples cadenas de texto a **objetos inteligentes.** En vez de pegar strings con barras manuales, interactuás con archivos y carpetas llamando métodos directos sobre una ruta.

**Qué problema resuelve:**

 Elimina el problema clásico de incompatibilidad de sistemas operativos (Windows usa `\` y Linux/Mac usa `/`) . Resuelve de raíz los errores de tipeo y la necesidad de usar funciones viejas y dispersas como `os.path.join`, `os.listdir` o `os.path.exists`, concentrando toda la manipulación del sistema de archivos en una sola interfaz limpia.

**Ejemplo mínimo de código (Tu pipeline RAG en** **EcoTandil-Auditor** **):**

```python
from pathlib import Path

# 1. Crea el objeto ruta a tu carpeta de conocimiento
data_dir = Path("data")

# 2. Busca todos los PDFs dentro del directorio
pdf_files = list(data_dir.glob("*.pdf"))

# 3. Itera extrayendo metadatos limpios para cada documento
for pdf in pdf_files:
    print(f"Indexando: {pdf.name} | Extensión: {pdf.suffix}")
```

**La trampa o error común:**

- **Tratar el** **Path** **como string directamente:** Muchas librerías viejas o funciones de bajo nivel esperan un `str` plano y fallan si les pasás un objeto `Path` sin convertirlo con `str(mi_ruta)`.
- **Olvidar que** **.glob()** **devuelve un generador:** Si intentás indexar o medir el tamaño con `len(data_dir.glob("*.pdf"))`, va a fallar con `TypeError`. Siempre tenés que envolverlo en una lista: `list(data_dir.glob("*.pdf"))` como hiciste en `index_pdfs.py`.

### **Clases y funcionalidades más utilizadas**

- **Clase estrella:**
    - **Path**: Es prácticamente la única clase que vas a importar el 95% de las veces (`from pathlib import Path`).
- **Operador y métodos más usados en RAG y Pipelines:**
    1. **Operador** **/** **(Composición):** Une directorios de forma segura: `ruta_completa = Path("data") / "raw" / "documento.pdf"`.
    2. **.glob("*.ext")** **y** **.rglob("*.ext")** **:** Búsqueda por patrón; `.rglob` busca de forma recursiva en todas las subcarpetas.
    3. **.name** **,** **.stem** **,** **.suffix** **(Atributos de metadatos):**
    - Si el archivo es `ordenanza_pdt.pdf`:
        - `.name` devuelve `"ordenanza_pdt.pdf"`.
        - `.stem` devuelve solo el nombre `"ordenanza_pdt"`.
        - `.suffix` devuelve la extensión `".pdf"`.
    1. **.exists()** **/** **.is_file()** **/** **.is_dir()** **:** Verificaciones booleanas rápidas antes de intentar cargar un archivo.
    2. **.read_text(encoding="utf-8")** **/** **.write_text(...)** **:** Lee o escribe texto en una sola línea sin tener que abrir bloques `with open(...)`.
