**Qué es en criollo:** 

Es el "traductor universal" nativo de Python que agarra cualquier archivo binario crudo (una foto, un audio o un PDF) y lo convierte en **texto plano alfanumérico imprimible** (letras de la `A-Z`, números del `0-9`, `+` y `/`).

**Qué problema resuelve:** 

Los protocolos de la web y las APIs de LLMs (como Gemini) viajan en formato **JSON**. Un JSON solo soporta texto; si intentás meterle los bytes binarios de una imagen JPG directamente, el archivo se corrompe o la API te rechaza la petición HTTP. `base64` resuelve esto "camuflando" los bytes como un string de texto que viaja seguro dentro del JSON.

**Ejemplo mínimo de código:**

```python
import base64

# 1. Tenés los bytes de la foto (subida por Streamlit o leída en disco)
with open("residuo.jpg", "rb") as f:
    image_bytes = f.read()

# 2. b64encode convierte bytes binarios a bytes en Base64
raw_b64 = base64.b64encode(image_bytes)

# 3. decode("utf-8") lo transforma en un string común para el JSON
encoded_image = raw_b64.decode("utf-8")

# 4. Estructura que le mandás a la API de Gemini
input_data = [{"type": "image", "data": encoded_image, "mime_type": "image/jpeg"}]
```

**La trampa o error común:**

- **Olvidar el** **.decode("utf-8")** **:** `base64.b64encode()` devuelve un objeto `bytes` (`b'...'`), no un texto `str`. Si mandás ese objeto a un JSON o al SDK sin decodificarlo, Python te tira un error como `TypeError: Object of type bytes is not JSON serializable`.
- **Costo oculto en tamaño (~33% más pesado):** Codificar en Base64 infla el peso del archivo un 33%. Para imágenes chicas va bárbaro, pero mandar videos o PDFs gigantes en Base64 puede superar el límite del payload de la API (en esos casos se usa la API de subida de archivos tipo `client.files.upload()`).

### **Funciones más utilizadas**

1. **base64.b64encode(bytes_data)** **:** Convierte datos binarios a bytes codificados en Base64.
2. **base64.b64decode(base64_string)** **:** La operación inversa; agarra el texto Base64 que te devuelve un modelo generador de imágenes y lo reconstruye a archivo de imagen real en disco.
3. **base64.urlsafe_b64encode(...)** **:** Igual que el normal, pero reemplaza caracteres conflictivos (`+` y `/`) por  y `_` para poder pasar tokens seguros adentro de URLs web sin romper la navegación.
