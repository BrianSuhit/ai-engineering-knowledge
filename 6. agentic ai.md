**Qué es en criollo el tema:** 

Es un LLM metido adentro de un bucle de control (`while`) que tiene autonomía para iterar, evaluar sus propios pasos y decidir si necesita seguir trabajando o si ya cumplió el objetivo.

 La diferencia clave con el prompting tradicional es que no es una llamada lineal de un solo tiro (*single-turn*), sino un proceso iterativo de ejecución continua donde el modelo gobierna su propio flujo de avance.

**Qué problema resuelve:** 

Resuelve tareas complejas de múltiples pasos que no se pueden solucionar de un solo tiro (*single-turn*). Permite que el sistema descomponga un objetivo grande en subtareas, verifique sus propios resultados intermedios y se auto-corrija si comete un error. Si no lo implementás, el modelo queda ciego ante sus propias fallas: devuelve la primera alucinación que genera, es incapaz de ejecutar acciones externas y no puede iterar hasta que la solución sea correcta.

**Ejemplo mínimo de código (Control de flujo con bucle):**

```python
from google import genai

client = genai.Client()
historial = ["Objetivo: corregir el bug en la función."]
iteracion = 0
MAX_ITER = 3

while iteracion < MAX_ITER:
    iteracion += 1
    
    prompt = f"Estado: {historial}. Si está arreglado respondé 'LISTO', sino la corrección."
    
    respuesta = client.interactions.create(
        model="gemini-4-hydrogen",
        input=prompt,
        generation_config={"thinking_level": "low"}
    )
    
    salida = respuesta.output_text
    historial.append(salida)
    
    # Condición de corte autónoma
    if "LISTO" in salida:
        print(f"Objetivo cumplido en el paso {iteracion}.")
        break
else:
    # Salvaguarda: si agotó las iteraciones sin resolver, se corta la ejecución
    print("Se alcanzó el límite máximo de iteraciones sin resolver el objetivo.")
    
    
```

**La trampa o error común:** 

La **degradación acumulativa del contexto** y los **bucles infinitos con explosión de costos**. Si el agente alucina o comete un error en el paso 1 y ese texto se reinyecta ciegamente al historial de la siguiente vuelta, el modelo asume su propio error como un hecho consumado; esto genera un bucle de decisiones rotas que satura la ventana de contexto y consume miles de tokens en segundos si no hay límites de iteración ni validación determinista.

**Arquitectura del ecosistema agéntico:** 

Este bucle de control (`while`) es el motor base. Sobre este patrón de ejecución se montan las capacidades que le dan alcance operativo al agente:

- **Tools:** Funciones de código tradicionales (scripts locales, APIs, llamadas al sistema) que el modelo invoca para actuar sobre el entorno.
- **Skills:** Paquetes de instrucciones procedimentales y flujos predefinidos que guían al agente sobre cómo resolver un tipo específico de tarea.
- **RAG:** La memoria documental y de conocimiento externo a la que el agente consulta cuando necesita recuperar contexto técnico privado antes de decidir.
- **MCP (Model Context Protocol):** El estándar de comunicación para conectar al agente de forma desacoplada con fuentes de datos, servidores de herramientas y entornos de ejecución externos.
